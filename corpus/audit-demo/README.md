# audit-demo

<!-- slopcheck: off -->

Twelve short documents, six per side, so `sloprefine audit` runs out of the box
and the enrichment table in the main README reproduces.

**These are not evidence.** Both sides were written by hand to exercise the
mechanism: the machine side is deliberately loaded with markers, the human side
deliberately free of them. Every effect size you get from this pair is an
artifact of that construction, and `x inf` verdicts just mean the human side
happens to contain zero instances.

Replace both directories with your own corpora before believing any number.
For the machine side, use output from the models you actually use. For the
human side, use your own writing from before you started using them.
